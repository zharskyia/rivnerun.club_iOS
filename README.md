# Rivne Running Club для iOS

Нативний iOS-застосунок на SwiftUI, що переносить основні екрани й стиль сайту [rivnerun.club](https://rivnerun.club/) на iPhone — за тією самою архітектурою, що й Android-версія цього клубу.

## Можливості

- П'ять основних вкладок: головна, клуб, забіги, тренування та контакти.
- Головна: статистика, найближчі тренування, новини, товари й підтримка клубу. Заголовок і логотип клубу розміщені на жовтому фоні; логотип гнучкий — масштабується відповідно до ширини екрана.
- Клуб: історія, засновники, партнери та рекорди клубу (окремі вкладки за аматорами й засновниками).
- Забіги: перелік подій із фільтром за рівнем підготовки.
- Тренування та контакти: нативні сторінки з розкладом і соціальними мережами клубу.
- Усі внутрішні сторінки клубу, новин і магазину — нативні екрани SwiftUI, без вбудованого браузера.
- Під час запуску застосунок завантажує новини, розклад, забіги, каталог, контакти та інформаційні сторінки з сайту й показує їх на нативних екранах. Останній успішно отриманий стан кешується у файлі для роботи без мережі.
- Новина відкривається з повним текстом і фотогалереєю зі своєї сторінки (не лише анотацією зі списку); текст і фото кешуються, є повторна спроба при помилці мережі.
- Тренування показуються розділеними на найближчі та ті, що вже відбулися.
- Потягнути вниз на будь-якій вкладці, у списку новин чи в магазині — оновлює дані з сайту; кнопка «Повторити» на банері помилки повторює оновлення вручну.
- Якщо окрема сторінка сайту недоступна або не містить очікуваних даних, для цього розділу зберігається остання успішно завантажена версія; застосунок показує точне повідомлення про часткове чи повне оновлення (скільки розділів, коли востаннє оновлено).
- Фото в новинах можна відкрити на весь екран дотиком.
- Форми вступу до клубу та замовлення товару готують чернетку листа в поштовому застосунку телефона (адреса, тема й текст заповнюються автоматично).
- Форма вступу має поля для персональних даних, вибір дати народження й параметрів зі списку; подати заявку можна лише після заповнення всіх обов'язкових полів і підтвердження обох згод (чекбокси мають чіткий контур, щоб їх було добре видно).
- Екран підтримки показує надані реквізити картки жирним шрифтом і має клікабельну адресу електронної пошти.
- Зовнішні посилання на соціальні мережі відкриваються у Safari або відповідних застосунках.

Для оновлення даних і завантаження зображень потрібен доступ до Інтернету. Перший запуск без мережі використовує вбудовані початкові дані; після успішного оновлення остання версія доступна з кешу.

### Спільний конфіг скрейпінгу

Так само, як Android-версія, застосунок тягне правила розбору HTML сайту (регулярні вирази) з [`scrape-config.json`](scrape-config.json) — локальна копія тут лише для довідки, а застосунок на старті намагається оновити її з того самого віддаленого джерела (`raw.githubusercontent.com/zharskyia/rivnerun_api`), яким користується Android. Це дозволяє виправляти парсинг після зміни верстки сайту без випуску нової версії застосунку. Деталі формату — у `scrape-config.README.md` в репозиторії [rivnerun.club_android](https://github.com/zharskyia/rivnerun.club_android) (формат однаковий для обох платформ; на iOS регулярки виконуються через `NSRegularExpression` замість Kotlin `Regex`, але синтаксис патернів сумісний).

## Вимоги

- Mac з macOS та Xcode (рекомендовано актуальну стабільну версію Xcode 15 або новішу).
- iOS SDK 17.0 або новіший (мінімальна підтримувана версія застосунку — iOS 17.0).
- Для симулятора — iOS Simulator, що встановлюється разом з Xcode. Для фізичного iPhone — кабель Lightning/USB-C та Apple ID, доданий до Xcode.
- Безкоштовного Apple ID достатньо для запуску на власному iPhone (підпис Development); платний Apple Developer account потрібен лише для Ad Hoc/TestFlight/App Store розповсюдження.

## Відкрити проєкт в Xcode

1. Завантажте або розпакуйте папку `rivnerun.club_iOS` на Mac.
2. Відкрийте `RivneRunningClubApp.xcodeproj` (двічі клацніть у Finder або `File > Open` в Xcode).
3. Дочекайтеся, поки Xcode проіндексує проєкт (панель активності зверху).
4. Якщо Xcode запропонує "Trust and Open", підтвердьте.

Альтернатива для розробників, які воліють Swift Package Manager: `Package.swift` у корені проєкту описує той самий цільовий застосунок (`swift build` зберуть код, але для запуску на симуляторі/пристрої все одно потрібен `.xcodeproj`, оскільки SwiftPM executable не підписується і не встановлюється на iOS сам по собі).

## Запуск на симуляторі

1. У верхній панелі Xcode поруч зі схемою `RivneRunningClubApp` відкрийте список пристроїв і виберіть будь-який iPhone Simulator (наприклад, iPhone 15).
2. Якщо потрібного симулятора немає в списку, додайте його через **Xcode > Settings > Platforms** (завантаження iOS Simulator runtime) або **Window > Devices and Simulators > Simulators > +**.
3. Натисніть ▶ **Run** (або `Cmd+R`). Xcode збере застосунок, запустить симулятор і встановить застосунок автоматично.
4. Симулятор повинен мати доступ до Інтернету (зазвичай використовує мережу Mac без додаткових налаштувань), щоб завантажити новини, товари й розклад із `rivnerun.club`.

## Запуск на фізичному iPhone

1. Підключіть iPhone до Mac кабелем Lightning/USB-C. На iPhone підтвердьте діалог **Довіряти цьому комп'ютеру?**.
2. У Xcode виберіть ваш iPhone у списку пристроїв (поруч зі схемою `RivneRunningClubApp`) замість симулятора.
3. Відкрийте вкладку проєкту: клацніть на `RivneRunningClubApp` у навігаторі зліва → вкладка **Signing & Capabilities** для таргета `RivneRunningClubApp`.
4. Увімкніть **Automatically manage signing** і виберіть свій **Team** (увійдіть через **Xcode > Settings > Accounts**, якщо Apple ID ще не додано — безкоштовного особистого Apple ID достатньо).
5. Натисніть ▶ **Run** (`Cmd+R`). Xcode підпише й встановить застосунок на iPhone.
6. Якщо на iPhone з'явиться повідомлення **Untrusted Developer** (при першому запуску застосунку від нового Apple ID): відкрийте **Налаштування > Основні > VPN і управління пристроєм**, виберіть профіль розробника й натисніть **Довіряти**. Після цього запустіть застосунок ще раз з Xcode або безпосередньо з головного екрана iPhone.
7. Переконайтеся, що iPhone підключений до Wi-Fi або мобільної мережі — без Інтернету застосунок покаже лише вбудовані початкові дані.

Застосунок, підписаний безкоштовним Apple ID (Development-підпис), працює на пристрої 7 днів, після чого Xcode потрібно перезібрати й перевстановити (`Cmd+R`) для продовження.

## Як зібрати файл для встановлення на iPhone (.ipa)

Для розповсюдження поза Xcode (Ad Hoc, TestFlight) потрібен архів `.ipa` замість прямого запуску з Xcode.

1. Увійдіть у ваш Apple Developer Team у Xcode (**Signing & Capabilities**, див. крок 4 вище).
2. Відкрийте **Product > Archive** (потрібно вибрати схему для реального пристрою або "Any iOS Device", не симулятор).
3. Після архівування у вікні Organizer натисніть **Distribute App** → **Ad Hoc** або **Development**.
4. Збережіть експортований архів — отримаєте `.ipa`, який можна встановити на iPhone (через Apple Configurator, TestFlight або MDM).

Також у репозиторії є скрипт `build_ipa.sh`, що автоматизує ці ж кроки через `xcodebuild` (`ExportOptions.plist` налаштовує метод експорту):

```bash
./build_ipa.sh
```

Готовий `.ipa` з'явиться в `build/ipa/`.

Важливо: збірка `.ipa` можлива лише на macOS з Xcode і дійсним сертифікатом підпису Apple — на Windows/Linux це зробити неможливо.

## Якщо виникла проблема

- **Xcode повідомляє про відсутній SDK:** відкрийте **Xcode > Settings > Platforms** і встановіть iOS 17 (або новішу) платформу.
- **Помилка підпису (`Signing for "RivneRunningClubApp" requires a development team`):** увімкніть **Automatically manage signing** і виберіть Team на вкладці **Signing & Capabilities**.
- **Симулятор не запускається:** перевірте вільне місце на диску й спробуйте **Device > Erase All Content and Settings** для проблемного симулятора, або виберіть інший у списку.
- **iPhone не з'являється в списку пристроїв Xcode:** перевірте кабель, підтвердьте діалог довіри на iPhone, і що iPhone розблокований; за потреби перезапустіть Xcode.
- **"Untrusted Developer" на iPhone:** довірте профіль розробника в **Налаштування > Основні > VPN і управління пристроєм**.
- **Застосунок запускається, але новини/товари не завантажуються:** перевірте підключення Mac (для симулятора) або iPhone (для пристрою) до Інтернету; застосунок покаже попередження про частково застарілі дані, якщо якийсь розділ сайту недоступний.

## Тести

Юніт-тести живуть у SwiftPM-пакеті (`Tests/RivneRunningClubAppTests`) і перевіряють чисту логіку без мережі: розбір HTML, формат повідомлень про оновлення, кодування `mailto:`-посилань, валідацію й (де)серіалізацію конфіга та знімка. Частина тестів парсерів використовує ті самі збережені сторінки сайту, що й тести Android-проєкту (`Tests/RivneRunningClubAppTests/Fixtures/*.html`, копії з `rivnerun.club_android/app/src/test/resources/site/`), тож обидві платформи перевіряються на однакових даних.

Оскільки `Package.swift` обмежує платформу до iOS, звичайний `swift test` у терміналі не збере пакет (потрібен симулятор). Щоб запустити тести:

1. У Xcode відкрийте саме `Package.swift` (**File > Open**, не `.xcodeproj`) — Xcode підхопить таргет `RivneRunningClubAppTests` автоматично.
2. Виберіть будь-який iPhone Simulator як пристрій призначення.
3. **Product > Test** (`Cmd+U`).

`.xcodeproj`, згенерований `generate_xcodeproj.py`, про тести не знає (бере файли лише з `RivneRunningClubApp/`) — для запуску тестів відкривайте саме `Package.swift`.

## Структура

- `Package.swift` — опис Swift Package для проєкту (альтернативний спосіб збірки без `.xcodeproj`, і єдиний спосіб запустити тести).
- `project.yml` — конфігурація для [XcodeGen](https://github.com/yonaskolb/XcodeGen), якщо потрібно перегенерувати `.xcodeproj` з нуля на Mac (`xcodegen generate`).
- `Sources/RivneRunningClubApp` — основне джерело коду застосунку (SwiftUI):
  - `RivneRunningClubApp.swift` — точка входу.
  - `ContentView.swift` — вкладки застосунку (Головна, Клуб, Забіги, Тренування, Контакти) і каркас екрана.
  - `NativePages.swift` — внутрішні нативні сторінки (новини, товари, вступ до клубу, підтримка, рекорди, партнери) і спільні елементи інтерфейсу.
  - `Models.swift` — моделі даних і вбудований початковий (offline) знімок клубу.
  - `ScrapeConfig.swift` — регулярні вирази для розбору HTML сайту, їх валідація та віддалене оновлення/кешування.
  - `ClubSiteRepository.swift` — завантаження сторінок сайту, розбір HTML, кеш новини й знімка даних, повідомлення про оновлення.
  - `TrainingSchedule.swift` — розбір дати тренування та розподіл на майбутні/минулі.
  - `AppTheme.swift` — кольори та спільні стилі інтерфейсу.
- `Tests/RivneRunningClubAppTests` — юніт-тести й HTML/JSON-фікстури (див. розділ «Тести» вище).
- `RivneRunningClubApp/` — копія тих самих файлів, на яку безпосередньо посилається `RivneRunningClubApp.xcodeproj` (генерується/синхронізується скриптом `generate_xcodeproj.py`; редагувати код слід у `Sources/RivneRunningClubApp`, а потім скопіювати сюди або перезапустити генератор).
- `generate_xcodeproj.py` — скрипт, що генерує `RivneRunningClubApp.xcodeproj/project.pbxproj` зі списку файлів у `RivneRunningClubApp/` (запускається Python 3 на будь-якій ОС, не вимагає Mac).
- `scrape-config.json` — локальна копія спільного (з Android) конфіга правил скрейпінгу сайту; джерело істини — однойменний файл у репозиторії `rivnerun_api`.
